## 1. Прогнозирование стоимости недвижимости в Турции

Командный проект, посвящённый анализу рынка недвижимости Турции и разработке модели машинного обучения для прогнозирования стоимости объектов недвижимости.

### Основные возможности

- Анализ и предварительная обработка данных о недвижимости.
- Исследование характеристик объектов недвижимости.
- Обучение модели машинного обучения для прогнозирования стоимости.
- Получение прогнозируемой стоимости недвижимости на основе введённых характеристик.
- Отображение статистических показателей и аналитических графиков.
- Оценка точности работы модели на тестовых данных.

### Входные параметры модели

Для прогнозирования стоимости используются следующие характеристики:

- Площадь недвижимости.
- Количество комнат.
- Возраст здания.
- Тип недвижимости.
- Город расположения.

## 2. Рекомендательная система фильмов

Проект представляет собой рекомендательную систему, предназначенную для подбора фильмов на основе пользовательских оценок и жанровых характеристик.

Система использует методы машинного обучения и анализа сходства для формирования рекомендаций.

### Основные возможности

- Формирование списка популярных фильмов.
- Поиск фильмов, похожих по пользовательским оценкам.
- Подбор фильмов на основе жанров.
- Формирование персональных рекомендаций для пользователей.
- Сохранение пользовательских оценок фильмов.
- Выбор количества отображаемых рекомендаций (от 1 до 100).

### Используемые алгоритмы

**1. Коллаборативная фильтрация**

Используется косинусное сходство для определения похожести фильмов на основе пользовательских оценок.

**2. Контентная фильтрация**

Используется TF-IDF для преобразования жанровых характеристик фильмов в числовые признаки и последующего вычисления сходства.

**3. Ранжирование популярных фильмов**

Применяется взвешенная оценка, учитывающая средний рейтинг фильма, количество пользовательских оценок и общий рейтинг датасета.

### API

Для взаимодействия с рекомендательной системой реализовано REST API на FastAPI.

| Метод | Назначение |
|---|---|
| `GET /popular` | Получение популярных фильмов |
| `GET /similar` | Поиск похожих по оценкам фильмов |
| `GET /content` | Поиск фильмов по жанрам |
| `GET /user/{user_id}` | Получение персональных рекомендаций |
| `GET /rate` | Сохранение пользовательской оценки |
